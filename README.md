## 这是什么

**MTM** 把「没有官方 API 的外卖平台」（美团 · 京东秒送 · 淘宝闪购 · 抖音即时零售 · 快手即时零售）变成 **AI 可操作的统一后台** —— 跨平台统一经营。

> **持续运营交给 AI，重要决策留给你。**

商户用自己的 AI 管店：接单、回评价、改价、上下架、盯异常，它 7×24 在做。
而它一直在学 —— 一线实战经验持续沉淀成判断标准，平台规则变化自动跟上。
